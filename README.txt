MTG Limited Grader v1

GitHub Pages setup:
1. Upload ALL files in this folder to the ROOT of your repository.
2. GitHub repository > Settings > Pages.
3. Source: Deploy from a branch.
4. Branch: main, folder: /(root), Save.
5. Open the Pages URL in Safari.
6. Share > Add to Home Screen.

DSK is added automatically on first launch by loading booster cards from Scryfall.
The app supports additional sets: enter any Scryfall set code on the Sets screen.
Ratings are saved in local browser storage. Use Data > Export backup regularly.
